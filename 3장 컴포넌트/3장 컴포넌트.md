# 3장 컴포넌트

## 3.1 클래스형 컴포넌트

컴포넌트 선언하는 방식

1. 함수형 컴포넌트
2. 클래스형 컴포넌트

클래스형 컴포넌트와 함수형 컴포넌트의 차이점

1. 클래스형 컴포넌트는 state 기능 및 라이프사이클 기능을 사용할 수 있다.
2. 임의 메서드를 정의할 수 있다.

함수형 컴포넌트의 장점

1. 클래스형 컴포넌트보다 선언하기가 훨씬 편하다.
2. 메모리 자원도 덜 사용한다.
3. 함수형 컴포넌트를 사용하는 것이 결과물의 파일 크기가 더 작다.

함수형 컴포넌트의 단점

- state와 라이프사이클 API의 사용이 불가능하다. -> Hooks 기능을 통해 해결 가능

※ 리액트 공식 매뉴얼: 컴포넌트를 새로 작성할 때 함수형 컴포넌트와 Hooks를 사용하도록 권장
